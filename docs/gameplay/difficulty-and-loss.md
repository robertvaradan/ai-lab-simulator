# Difficulty and loss

## Difficulty profiles

The first marketing slice must use the Standard profile.

Later versions can include Relaxed, Cutthroat, and Sandbox profiles.

All profiles must use the same rules.

A profile can change declared numeric parameters.

A profile must not change hidden parameters in response to player performance.

A profile must not secretly reduce Competitor progress because the player is behind.

A profile must not secretly create a rescue event.

## Bankruptcy

Bankruptcy must be a hard campaign loss.

The bankruptcy rule must use an explicit condition.

The interface must show the Cash trend before bankruptcy.

The interface must show committed future costs before bankruptcy.

The interface must show failed obligations before bankruptcy.

The player must be able to abandon a campaign before bankruptcy.

Campaign abandonment must require explicit confirmation.

## Other terminal states

The game can add other terminal states later.

A terminal state must identify its causal rules in the Simulation Trace.

No other terminal state is canonical for the first marketing slice.
